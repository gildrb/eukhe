Run a JavaScript script in the background that spawns subagents and returns one result. Use when the user asks for a workflow (`/dynamic-workflow`) or a task splits into many independent agent tasks; step-by-step dependent work stays in your loop.
Returns the run id at once (progress: `/workflows`); the result arrives as a `[job-settled job:workflow-<id> status:ok|error|aborted]` message that starts a turn. NEVER poll: finish other work, then end your turn. One run per request.
Script: async function body starting with a pure literal `export const meta = { name, description, phases: [{ title }] }`; globals `agent(prompt, opts?)`, `parallel(thunks)`, `pipeline(items, ...stages)`, `phase(title)`, `log(message)`, `args`, `budget`. Before writing a script, read `skill://subagents/references/workflow.md` (API, rules, examples, `resume`).
