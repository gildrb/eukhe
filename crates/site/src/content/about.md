# Eukhe

Eukhe is an agent harness that works a task with no person watching, counts it done only when the user's checks pass on the final code, and gives a report at the end. The name is εὐχή, Greek for wish.

> διὸ δὴ καὶ ὄκνος τις αὐτῶν ἅπτεσθαι, μὴ εὐχὴ δοκῇ εἶναι ὁ λόγος,
> ὦ φίλε ἑταῖρε.
> So there is some hesitation to touch these things, lest the
> argument seem a mere wish, my dear friend. (Plato, Republic 5.450d)

## Maker

Eukhe is made by Gil Rodrigues ([gildrb.com](https://gildrb.com)), a designer and developer. The source is at [github.com/gildrb/eukhe](https://github.com/gildrb/eukhe) under the Apache-2.0 license. The releases for macOS (Apple Silicon) and Linux (x64, arm64) are built from it.

## This site

eukhe.com shows Eukhe's README, with Greek epigraphs of its own, in an editor that works as Neovim does. Visual mode selects and a yank copies; the files stay as they are. On a phone, the same editor scrolls by touch.
