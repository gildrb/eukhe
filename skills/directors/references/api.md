# directors API

- `directors.remind(text: str) -> dict`: puts a reminder on the Director stack; its text leads the next autonomous continuation and waits on the stack until one comes. Returns the Director stack (`stack`, bottom first).
- `directors.force_tool(tool: str, tries: int = 1) -> dict`: forces the next requests to call `tool` until a response calls it; after `1 + tries` requests without the call the run fails and the forced call leaves the stack. Returns the Director stack (`stack`, bottom first).
- `directors.acceptance() -> dict`: the task's acceptance: `label` (`checks_passed_unconfined`, `checks_passed_not_certified`, `failed`, `unverified`), `state`, `revision`, `checks` (each `spec`, once judged `result` with `verdict`, `summary`, `evidence`, and once measured `strength` with `caught`, `ran`, `planned` and `survivors`), `attacks` (the blind attacks on the checks: each `outcome` `survived`, `clean` or `unrun`, `path`, `witness`, `required`, `got`, `note`), `claimed`, `tries`, `maxReturns`, and `lastEnd` once a claim ended. `checks_passed_not_certified`: every check passed but none was shown to catch deliberate breaks of the changed code (a weak check, or judges only without two clean blind attacks), or a blind attack's wrong code passed them too, so the task is not done. Read-only: the task's owner sets the checks.
